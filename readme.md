# Warehouse Inventory Report Generator

Automated report generation tool for warehouse inventory analysis. Produces professional reports in Word (.docx) format from raw inventory data, with PDF and PowerPoint variants planned.

## Dataset

This project uses the **Inventory Analysis Case Study** dataset from Kaggle.

**Source:** [https://www.kaggle.com/datasets/bhanupratapbiswas/inventory-analysis-case-study](https://www.kaggle.com/datasets/bhanupratapbiswas/inventory-analysis-case-study)

**Required files (place in `data/` folder):**

| File | Description |
|------|-------------|
| `BegInvFINAL12312016.csv` | Beginning of year inventory (Jan 2016) |
| `EndInvFINAL12312016.csv` | End of year inventory (Dec 2016) |
| `InvoicePurchases12312016.csv` | Purchase invoices for the year |
| `2017PurchasePricesDec.csv` | Product catalog with sale and purchase prices |

**Data overview:**
- 79 stores across 67 cities
- ~8,000–9,600 SKUs (beverage/liquor products)
- 128 active suppliers
- Fiscal year: January–December 2016

## Project Structure

```
├── data/                       # Raw CSV files (not tracked)
├── outputs/                    # Generated reports and charts (not tracked)
├── src/
│   ├── report_config.py        # Shared format configuration (colors, fonts, sizes)
│   ├── report_data.json        # Processed metrics (generated by data pipeline)
│   └── generate_docx.js        # Word report generator (docx-js)
├── .gitignore
└── README.md
```

## Report Sections

1. **Executive Summary** — KPIs: stores, SKUs, avg margin, vendor count
2. **Inventory Overview** — Top 10 stores by EOY value, stock delta analysis
3. **Margin Analysis** — Top/bottom 10 products by margin percentage
4. **Stock Rotation** — Fastest and slowest moving products, dead stock count
5. **Supplier Analysis** — Top 10 suppliers by spend, freight, payment terms

## Requirements

- **Node.js** (v18+)
- **npm package:** `docx` (`npm install -g docx`)
- **Python 3.10+** (for data processing)

## Usage

```bash
# 1. Process raw data into report_data.json
python src/process_data.py

# 2. Generate Word report
node src/generate_docx.js
```

Output is saved to `outputs/WarehouseReport.docx`.
